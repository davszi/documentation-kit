# Agent entrypoint

Read `docs/project/PROJECT_CONTEXT.md` once for orientation, unless it is
already loaded. Initialize the pinned `.docs-kit` submodule before relying on
its rules. If required shared policy is missing, report it and resolve the
prerequisite before proceeding with the work it governs.

## Read before the relevant action

Apply every matching route before its action. Load additional routes when
scope expands. Follow named topic and experiment links for task-specific
inputs. These routes grant no execution or publication permission.

| Before… | Read… |
|---|---|
| Staging, committing or rewriting Git history | `.docs-kit/rules/engineering/git.md` and the project's recorded validation requirements |
| Creating, editing, moving, reviewing, publishing or retiring documentation | `.docs-kit/rules/documentation.md` |
| Writing human explanations, mathematical content or visual evidence | `.docs-kit/rules/writing.md` |
| Building, checking, reviewing rendered output, publishing or changing the documentation site | `.docs-kit/rules/maintenance.md` and **Build and review** in `docs/project/PROJECT_CONTEXT.md` |
