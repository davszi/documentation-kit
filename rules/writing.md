# Writing pages for people

These guides apply to pages written for people. A page follows its record: the agent that did the work writes the record first, under [writing records](records.md), and a new page is made only when a person asked for one. The [documentation system](documentation.md#record-first-page-on-request) owns that order.

Read the focused guide for each kind of page content you change. This file is only their index; link to a guide's own section, not to this file.

| Guide | Owns |
|---|---|
| [Page design and review](writing/pages.md) | Page design, project-owned homepages, build-sheet pages, slide faces, completion and review |
| [Explanations and reading layers](writing/explanations.md) | Story and reading layers |
| [Figures, comparisons and access](writing/figures.md) | Figures and comparisons, interaction and access, run visuals and experiment lifecycle |
| [Mathematical explanation](writing/math.md) | Building formulas, notation and rendering |
| [Code excerpts and diagrams](writing/code.md) | Verified excerpts and data-backed diagrams |

Naming, honest claims and measured numbers follow [writing records](records.md) on pages as in records. The rules in these guides about what a code excerpt, a formula or an experiment visual may claim apply to records too; [excerpts, formulas and figures](records.md#excerpts-formulas-and-figures) names them.
